# 🏢 AI-Driven HR Intelligence & Recruitment Suite

## 🌟 Projektübersicht (Overview)
Ein hochmodernes System für das Personalwesen, das maschinelles Lernen und lokale Sprachmodelle (LLMs) nutzt, um die Mitarbeiterbindung zu optimieren und den Rekrutierungsprozess zu automatisieren. Dieses Projekt wurde mit einem Fokus auf **Datenschutz (GDPR-Compliance)** entwickelt, indem lokale KI-Modelle zur Analyse sensibler Personaldaten eingesetzt werden.

## 🚀 Kernfunktionen (Key Features)
*   **Predictive Attrition Modeling:** Vorhersage der Kündigungswahrscheinlichkeit von Mitarbeitern basierend auf über 30 Faktoren (Gehalt, Überstunden, Zufriedenheit) unter Verwendung von **Random Forest**.
*   **AI-Recruiter (Local LLM):** Integration von **Ollama (Llama3)** zur Durchführung und Analyse von Bewerbungsgesprächen, ohne dass Daten das interne Netzwerk verlassen.
*   **Performance & Burnout Tracking:** Identifizierung von Mustern, die zu Burnout führen könnten, durch Korrelation von Überstunden und Arbeitszufriedenheit.
*   **Executive Dashboard:** Ein interaktives Business-Intelligence-Tool, das komplexe Daten in handlungsorientierte Erkenntnisse (Insights) verwandelt.

## 📊 Business-Impact (Geschäftsnutzen)
*   **Kostenreduzierung:** Senkung der Fluktuationskosten durch frühzeitige Warnsignale.
*   **Effizienz:** Automatisierung der Vorauswahl von Bewerbern durch KI-gestützte Skill-Analyse.
*   **Datensicherheit:** Einsatz von On-Premise AI zur Einhaltung strengster Datenschutzrichtlinien.

## 🛠️ Tech Stack
*   **Frontend/Dashboard:** Streamlit
*   **Machine Learning:** Scikit-learn, Pandas, NumPy
*   **AI Engine:** Ollama (Llama3 / Mistral), LangChain
*   **Visualisierung:** Plotly, Go-Radar Charts, Seaborn
